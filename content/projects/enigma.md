A full-stack web app built with **React**, **Express.js**, and **Firebase**. One question a day, race to answer it the fastest, and climb the daily leaderboard.

## 🏗️ Project structure

- **Frontend** (`apps/frontend`): React 19 + Vite + Tailwind CSS (shadcn/ui)
- **Backend** (`apps/backend`): Express.js 5 server with Firebase Authentication and Cloud Firestore

## ⚙️ Tech stack

- React, TypeScript, Tailwind CSS, shadcn/ui
- Express.js + Firebase Admin SDK
- Cloud Firestore + Firebase Auth
- Turborepo (pnpm workspace), Docker + nginx deployment
