**DocuFlow** aims to reduce the hassle of applying for a document. It tells the user all the documents required for an application, so nothing gets missed.

## ⚙️ Technical details

- Frontend: **Next.js**
- Backend: **Express (Node.js)** along with Google generative AI (Gemini) API

Live at [docuflow-frontend.vercel.app](https://docuflow-frontend.vercel.app/).
