StockFlow is a comprehensive B2B order management platform designed for apparel and textile businesses. It bridges the gap between warehouse inventory managers, field sales agents, and retail customers — streamlining the entire order-to-delivery workflow through a modern, mobile-first interface.

## 🏢 Who is it for?

- **Warehouse Managers** — Manage inventory, track all orders, and coordinate dispatch
- **Field Sales Agents** — Place orders on-the-go using QR scanning and a simplified mobile interface
- **Customers / Retailers** — Receive orders accurately and track fulfillment status

## ✨ Key Features

### 📦 Inventory Management

- Full product catalog with images, variants, and size ranges
- Real-time stock tracking per variant and size group
- QR code generation for every item variant
- Bulk QR code printing for warehouse operations
- Stock automatically adjusts when orders are placed or cancelled

### 🧾 Order Management

- Multi-stage order workflow: **Draft → Pending → Packed → Dispatched**
- Real-time stock validation to prevent overselling
- Editable orders until dispatch
- Complete order audit trail with activity logs

### 📱 Sales Agent Tools

- Mobile-optimized interface for field work
- QR code scanning for quick item lookup and price checks
- Invoice generation with PDF export
- Access restricted to assigned customers and products only

### 🛠️ Admin Dashboard

- Overview of all orders across agents
- Filter by date range, agent, or status
- Manage customers, agents, and admins
- Dispatch management

## 👨‍💻 Tech Stack

Built with **Next.js 16**, **React 19**, **Tailwind CSS**, **Radix UI** on the frontend, and **Django** + **Python** on the backend.
