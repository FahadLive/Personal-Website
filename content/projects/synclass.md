**SynClass** is a real-time interactive classroom & quiz system. Run live quizzes, polls, and interactive sessions with your class in real time — attendees join by 6-character room code or QR code, no sign-up or install needed. This is a fork of [shad-ct/synclass](https://github.com/shad-ct/synclass).

## ✨ Features

- **Kahoot-style quizzes** — timed MCQs with live countdowns, per-question results, running leaderboard, and a final 3-place podium with confetti
- **Live polling** — ad-hoc polls with real-time results
- **Confusion meter** — attendees flag when they're lost
- **Screen freeze & buzz** — pause screens or buzz attendees to grab attention
- **Ad-hoc attendance** with acknowledgement log
- **Code/snippet broadcasting** and instant file drops
- **Live attendee roster** — hand-raise notifications, kick/control tools

## ⚙️ Tech stack

- Frontend: React 19, TypeScript, Vite, Tailwind CSS, Socket.io-client
- Backend: Node.js, Express, Socket.io
- Database: MongoDB (Mongoose)
