**Sessions** is a documentation hub of hands-on sessions and beginner-friendly tutorials, live at [sessions.justfahad.me](https://sessions.justfahad.me). It's built on **Eleventy LibDoc** (forked from [ita-design-system/eleventy-libdoc](https://github.com/ita-design-system/eleventy-libdoc)), an easy-to-use, content-focused starter for crafting slick, responsive documentation.

## ✨ Key features

- Content-focused, accessible, and performant (vanilla JS components)
- Fuzzy and standard search modes
- Smart navigation and floating table of content
- Works without JavaScript, printable
- Light and dark modes, slick code highlighting, sandboxes
- Atom feed for blog content
