A Python script that helps you with text in **images & PDFs**.

## 🚀 Features

- Extract text from images and PDFs and print it to the terminal
- Save extracted text as an audio file (needs internet)
- Many more options provided on running the script

Uses **Tesseract-OCR** for text extraction, with multi-language support. Licensed under GPL-3.0.
