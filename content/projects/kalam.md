**കളം** (pronounced *kalam*) is a sleek web app for managing checklists directly from **Google Sheets**. It connects to a shared spreadsheet and provides a beautiful, collapsible interface for activity tracking — ideal for outreach teams, clubs, or any collaborative workflows. Live at [kalam-beta.vercel.app](https://kalam-beta.vercel.app).

## ✨ Features

- Interactive checklist UI synced with Google Sheets
- Role-based edit access — add `[!]` to an activity's name to make it uneditable
- Collapsible activity groups for better UX

## 🧠 Tech stack

- React + TypeScript
- Google Sheets API v4
- Google OAuth2 (token-based login)
- Tailwind CSS for styling
- Lucide React for icons
