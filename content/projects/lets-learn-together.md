**Let's Learn Together (LLT)** is a short and simple program to help my peers learn the basics of software development.

## 📚 Activities

1. **Introduction** — members of LLT get to know each other
2. **Git on local system** — install git, clone a repo, and push a screenshot
3. **Make a quiz** — write a simple Python quiz and submit a pull request
4. **LLT CLI intro** — complete the interactive intro at [ranger-nf.github.io/lets-learn-together](https://ranger-nf.github.io/lets-learn-together/)

A collaborative, community-driven project with checklists tracking each member's progress. *"Alone we can do so little; together we can do so much" — Helen Keller.*
