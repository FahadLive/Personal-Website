**Zooma** is a modern, real-time multiplayer game where players complete photo-based tasks in teams, with mentors reviewing submissions and managing leaderboards. Built with **Flutter & Django** — perfect for ice breaking, team building, and interactive activities. This is a fork of [Muflih-uk/Zooma](https://github.com/Muflih-uk/Zooma).

## 🎯 Core gameplay

- Room-based multiplayer — mentors create rooms, players join with room codes
- Photo-based tasks — players complete challenges by taking photos
- Real-time updates — live scoring, leaderboards, and notifications
- Mentor approval system — review and approve/reject submissions
- Dynamic scoring based on task difficulty

## 🚀 Technical features

- Cross-platform mobile app built with Flutter
- Automatic photo optimization and compression
- Secure file handling with validated uploads
- Clean, documented RESTful API
